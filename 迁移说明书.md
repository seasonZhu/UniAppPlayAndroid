## 项目背景

**项目名称：** UniAppPlayAndroid（玩Android客户端）

**原始状态：**
- 框架：uni-app Vue 2
- UI组件：uView UI 2.x
- 状态管理：Vuex
- 构建工具：webpack
- 编译目标：仅支持Android

**迁移需求：**
- 升级到最新 uni-app 版本（Vue 3）
- 支持编译为 wgt 文件
- 跨平台支持：iOS、Android、HarmonyOS Next

#### 3. Vuex → Pinia 重写

**原 store/index.js (Vuex)：**
```javascript
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export default new Vuex.Store({
  state: {
    userInfo: {
      hasLogin: false,
      cookie: '',
      profile: {}
    }
  },
  mutations: {
    storeLogin(state, payload) {
      state.userInfo = payload
    }
  }
})
```

**新 stores/user.js (Pinia)：**
```javascript
import { defineStore } from 'pinia'
import { ref } from 'vue'

export const useUserStore = defineStore('user', () => {
  // state → ref
  const userInfo = ref({
    hasLogin: false,
    cookie: '',
    profile: {}
  })

  // mutations → 普通函数
  const storeLogin = (payload) => {
    userInfo.value = payload
  }

  const storeLogout = () => {
    userInfo.value = {
      hasLogin: false,
      cookie: '',
      profile: {}
    }
  }

  const initUserInfo = () => {
    const hasLogin = uni.getStorageSync('hasLogin')
    if (hasLogin) {
      userInfo.value = {
        hasLogin: true,
        cookie: uni.getStorageSync('cookie') || '',
        profile: uni.getStorageSync('profile') || {}
      }
    }
  }

  return {
    userInfo,
    storeLogin,
    storeLogout,
    initUserInfo
  }
})
```

**使用方式变更：**
```javascript
// Vuex
import { mapState } from 'vuex'
computed: {
  ...mapState(['userInfo'])
}

// Pinia
import { useUserStore } from '@/stores/user.js'
const userStore = useUserStore()
const { userInfo } = userStore
```

**创建 config/http.js（全局拦截器）：**

核心特性：
1. Promise封装
2. 全局RequestManager管理loading
3. 每个API独立控制loading显示

```javascript
/**
 * 请求管理器 - 统一管理loading状态
 */
const RequestManager = {
  loadingCount: 0,
  isShowing: false,

  show(text = '加载中...') {
    this.loadingCount++
    if (!this.isShowing) {
      this.isShowing = true
      uni.showLoading({ title: text, mask: true })
    }
  },

  hide() {
    this.loadingCount--
    if (this.loadingCount <= 0) {
      this.loadingCount = 0
      if (this.isShowing) {
        this.isShowing = false
        uni.hideLoading()
      }
    }
  }
}

/**
 * 封装 uni.request
 */
function request(options) {
  return new Promise((resolve, reject) => {
    const showLoading = options.showLoading !== false
    const loadingText = options.loadingText || '加载中...'

    if (showLoading) {
      RequestManager.show(loadingText)
    }

    const finish = () => {
      if (showLoading) {
        RequestManager.hide()
      }
    }

    uni.request({
      url: httpConfig.baseUrl + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: header,
      timeout: options.timeout || 60000,
      success: (res) => {
        finish()
        if (res.statusCode === 200) {
          resolve(res.data)
        } else {
          reject(res)
        }
      },
      fail: (err) => {
        finish()
        reject(err)
      }
    })
  })
}

/**
 * API方法集合 - Loading控制规则
 */
export const api = {
  // 初始加载：显示loading
  banner: () => get(apiPaths.banner),

  // 分页：第一页显示，后续不显示
  normal: (page = 0) => get(apiPaths.normalArticle + page + '/json', {}, {
    showLoading: page === 0
  }),

  // 用户操作：不显示loading
  login: (username, password) => post(apiPaths.login + '?username=' + username + '&password=' + password, {}, {
    showLoading: true,
    loadingText: '登录中...'
  })
}

export default {
  install(app) {
    app.config.globalProperties.$api = api
    app.config.globalProperties.$requestManager = RequestManager
  }
}
```

**4. WebView标题跑马灯**

```javascript
/**
 * 计算标题显示宽度
 */
const calculateTitleWidth = (title) => {
  if (!title) return 0
  let width = 0
  for (let i = 0; i < title.length; i++) {
    const char = title.charAt(i)
    // 中文：2个宽度，英文：1个宽度
    if (/[\u4e00-\u9fa5]/.test(char)) {
      width += 2
    } else {
      width += 1
    }
  }
  return width
}

/**
 * 启动跑马灯
 */
const startTitleMarquee = (title) => {
  const titleWidth = calculateTitleWidth(title)
  const maxDisplayWidth = 26

  if (titleWidth <= maxDisplayWidth) {
    uni.setNavigationBarTitle({ title })
    return
  }

  let displayIndex = 0
  const marquee = () => {
    let displayTitle = ''
    let currentWidth = 0
    let i = displayIndex

    while (currentWidth < maxDisplayWidth && i < title.length) {
      const char = title.charAt(i)
      currentWidth += /[\u4e00-\u9fa5]/.test(char) ? 2 : 1
      displayTitle += char
      i++
    }

    displayTitle = displayTitle.slice(0, -1) + '…'
    uni.setNavigationBarTitle({ title: displayTitle })
    displayIndex = (displayIndex + 1) % title.length
  }

  marqueeTimer.value = setInterval(marquee, 500)
}
```

## 问题与解决方案

### 问题1：根目录缺少 index.html

**错误：**
```
请确认您的项目模板是否支持vue3：根目录缺少 index.html
```

**解决：** 创建 index.html 入口文件

### 问题2：uview-plus 样式找不到

**错误：**
```
Can't find stylesheet to import: uview-plus/index.scss
```

**解决：** 改用原生组件，移除 uview-plus 依赖

### 问题3：可选链操作符语法错误

**错误：**
```
Uncaught SyntaxError: Unexpected token .
title: launchInfo?.referrerInfo?.extraData?.arguments
```

**解决：** 全局替换 `?.` 为 `&&` 短路求值

### 问题4：uni.onNativeEventReceive 不是一个函数

**解决：** 添加平台条件编译
```javascript
// #ifdef APP-PLUS
if (typeof uni.onNativeEventReceive === 'function') {
  uni.onNativeEventReceive(...)
}
// #endif
```

### 问题5：API返回数据不显示

**原因：** API返回格式 `{ data: [...], errorCode: 0 }`

**解决：**
```javascript
// 错误
list.value = result

// 正确
list.value = (result && result.data) || []
```

### 问题6：搜索API 405错误

**原因：** 应该是POST请求但参数在URL中

**解决：**
```javascript
queryKeyword: (keyword, page) => post(
  apiPaths.queryKey + page + '/json?k=' + keyword
)
```

### 问题7：CORS跨域

**错误：**
```
Access to XMLHttpRequest blocked by CORS policy
```

**解决：** Vite proxy + 环境判断
```javascript
// H5使用代理
proxy: {
  '/api': {
    target: 'https://www.wanandroid.com',
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api/, '')
  }
}
```

### 问题8：初始页面无数据

**原因：** onLoad 中缺少 getNormalArticle() 调用

**解决：**
```javascript
onLoad(() => {
  getBanner()
    .then(() => getTopArticle())
    .then(() => getNormalArticle()) // 添加此行
})
```

### 问题9：WebView URL双重编码

**错误：**
```
file:///.../https%3A%2F%2Fjuejin.cn%2Fpost%2F...
```

**解决：**
```javascript
// 传递时编码
url: '/pages/web/index?url=' + encodeURIComponent(url)

// 接收时解码
const decodedUrl = decodeURIComponent(params.value.url)
```

### 问题10：首页显示"0 赞"不友好

**解决：** 将zan字段改为显示发布时间niceDate
```vue
<!-- 修改前 -->
<text class="zan">{{ item.zan || '0' }}</text>

<!-- 修改后 -->
<text class="time">{{ item.niceDate || '刚刚' }}</text>
```

### 问题11：HarmonyOS Next WebView崩溃

**错误：**
```
Error message: Parameter Error. The type of "permissionList" must be Array<Permissions>.
Error code: 401
```

**原因：** HarmonyOS Next 运行时对 WebView 组件的权限参数有严格要求

**解决方案：**

1. **更新 manifest.json 添加 HarmonyOS 配置**
```json
{
  "app-plus": {
    "distribute": {
      "harmonyos": {
        "abilities": []
      }
    }
  }
}
```

2. **pages.json 中 web-view 页面添加平台配置**
```json
{
  "path": "pages/web/index",
  "style": {
    "app-plus": {
      "bounce": "none"
    }
  }
}
```

3. **web-view 组件使用条件编译**
```vue
<template>
  <view>
    <!-- #ifdef APP-PLUS -->
    <web-view :src="decodedUrl"></web-view>
    <!-- #endif -->
    <!-- #ifndef APP-PLUS -->
    <web-view :src="decodedUrl" :update-title="false"></web-view>
    <!-- #endif -->
  </view>
</template>
```

**注意：** HarmonyOS 会自动处理 WebView 权限，不要手动传入 permissionList 属性

**参考文档：** `HarmonyOS部署指南.md`

## 最佳实践总结

### 1. Composition API 使用

**优先使用 `<script setup>`**
- 更简洁的语法
- 更好的性能
- 自动暴露变量给模板

### 2. 状态管理

**Pinia 相比 Vuex 的优势：**
- 更少的样板代码
- TypeScript支持更好
- 去除 mutations，只有 state, getters, actions
- 支持组合式API风格

### 3. HTTP请求

**统一拦截器的好处：**
- 集中管理loading
- 统一错误处理
- 自动添加token
- 便于调试和维护

### 4. 空状态处理

**首次加载标记：**
```javascript
const isFirstLoad = ref(true)

onLoad(() => {
  fetchData().finally(() => {
    isFirstLoad.value = false
  })
})
```

### 5. 平台兼容

**使用条件编译：**
```javascript
// #ifdef H5
// H5特有代码
// #endif

// #ifndef H5
// 非H5代码
// #endif
```

### 6. 性能优化

- 分页加载使用 `showLoading: page === 0`
- 用户操作不显示loading
- 并发请求使用Promise链
- 组件销毁时清除定时器

### 7. 用户体验

- 统一的空状态UI
- 智能的标题跑马灯
- 下拉刷新 + 上拉加载
- loading状态管理
- 错误提示

## 功能特性

### 1. 全局Loading管理

统一的 RequestManager 管理所有网络请求的loading状态：
- 并发请求自动计数
- 防止loading闪烁
- 每个API独立控制

### 2. 空状态优化

统一的空状态UI：
- 📭 图标
- "暂无数据" 文本
- 点击重新加载
- 首次加载优化

### 3. 下拉刷新

所有列表页面支持下拉刷新：
- 首页：单列刷新
- 项目/公众号：多tab独立刷新
- 使用 scroll-view refresher 模式

### 4. 标题跑马灯

WebView页面长标题自动滚动：
- 智能宽度计算（中文x2，英文x1）
- 26字符宽度限制
- 每500ms滚动一次

### 5. 体系页面

彩色标签：
- 8种预设颜色
- 随机但确定的颜色分配
- 提升可读性

## 开发规范

### 代码风格

- 使用 `<script setup>` 语法
- 优先使用 Composition API
- 统一使用 `ref` 和 `computed`
- 避免使用可选链操作符

### 命名规范

- 文件名：小写，连字符分隔
- 组件名：大驼峰
- 变量/函数：小驼峰
- 常量：大写下划线

### 注释规范

```javascript
/**
 * 函数功能说明
 * @param {Type} param - 参数说明
 * @returns {Type} 返回值说明
 */
const functionName = (param) => {
  // 实现
}
```

## 常见问题 FAQ

**Q: 为什么不使用 uView Plus？**
A: uView Plus 与 uni-app Vue 3 版本存在样式兼容问题，改用原生组件更稳定。

**Q: 为什么移除可选链操作符？**
A: uni-app 的某些编译目标不支持 ES2020 语法，需使用 `&&` 短路求值替代。

**Q: 如何处理跨平台兼容？**
A: 使用条件编译 `#ifdef` 和 `#ifndef`。

**Q: 为什么首次加载要特殊处理？**
A: 避免在数据加载完成前显示"暂无数据"，提升用户体验。
